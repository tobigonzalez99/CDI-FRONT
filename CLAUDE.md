# cdi-frontend

Frontend del Club Deportivo Independencia (Next.js 16 + React 19 + Tailwind v4 + shadcn/ui).
Corre en el puerto 3000 y consume la API del backend (`../cdi-backend`, puerto 4000).

El contexto compartido con el backend —contrato de la API, modelo de datos y reglas de
trabajo— está en `../CLAUDE.md`, en la raíz del workspace. Si esa carpeta no está
disponible, hay una copia de respaldo en [`docs/contexto-workspace.md`](docs/contexto-workspace.md).
